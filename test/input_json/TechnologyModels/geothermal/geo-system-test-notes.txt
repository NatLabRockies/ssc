These tests represent the design and performance code before a major overhaul to the UI equations and subsequent refactoring of the geothermal system model in SSC. We anticipate that the input file for each case will need to be updated as we change the values passed from the UI to the cmod. Because the starting point model calculated net capital cost and fixed operating cost in the UI, we manually add those values to both the input and output jsons. Future versions of the code will likely calculate these values in ssc, and we want to be able to compare them to the orignal values.
